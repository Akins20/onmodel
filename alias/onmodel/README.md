# onmodel

`npx onmodel` runs [`@akins20/onmodel`](https://www.npmjs.com/package/@akins20/onmodel):
images, sprites and sets kept on model with Gemini's image models. It paints from your
product's real brief and references, measures every candidate, packs sprite sheets,
and derives the icons, store graphics and link previews apps, games and pages need.

This package only points at `@akins20/onmodel`, at the same version. Use `npx onmodel`
or `npx @akins20/onmodel`, or install it with `npm i -g @akins20/onmodel`.

Documentation: https://github.com/Akins20/onmodel#readme
